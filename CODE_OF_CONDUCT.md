# Code of Conduct

This project puts root-level software on other people's computers. The way we
treat each other here has to meet the same standard as the code: careful,
honest, and respectful of the trust involved.

## Our standard

Everyone taking part — in issues, pull requests, discussions, security reports
and the project's pages — is expected to:

- **Be respectful.** Disagree with ideas, not people. No harassment, insults,
  slurs, personal or political attacks, unwelcome sexual attention, or
  publishing anyone's private information.
- **Be honest about the code.** Report what you actually observed. Say what you
  tested and what you did not. If you were wrong, say so; the changelog of this
  project is full of the maintainer doing exactly that.
- **Handle security with care.** Do not post a working exploit for an
  unpatched problem in a public issue. Use the address in
  [SECURITY.md](SECURITY.md). Reporters are credited, never blamed.
- **Respect other people's networks.** probesource and the other active tools
  send packets. Discussing their use against hosts you do not own or have
  written permission to test is out of bounds here.
- **Welcome newcomers.** Many people arrive at this repository from a search
  for "Wi-Fi connected but no internet". Assume they are competent and worried,
  and answer the question they asked.

## Scope

This applies to every space the project runs: the GitHub repository (issues,
pull requests, discussions, wiki), the GitHub Pages site, and any email sent
to the maintainer about the project.

## Enforcement

Report unacceptable behaviour to **spilled-bowline0j@icloud.com**. Reports are
read by the maintainer, kept confidential, and acted on. Responses range from a
private word, through editing or removing content, to a temporary or permanent
ban from the project's spaces, depending on severity and repetition. The
maintainer is bound by this document too; if the complaint is about the
maintainer, say so and expect a straight answer.
